# Support

Pick whichever suits you.

| What you need | Where to go |
|---|---|
| How something works | The project's README and `docs/`. Most repositories document setup, configuration, and troubleshooting there |
| Report a bug, request a feature | Open an issue on the repository it affects, not here. That puts it in front of the maintainers who can fix it |
| Report a security vulnerability | Don't open a public issue. See [SECURITY.md](SECURITY.md) |
| Report a Code of Conduct violation | Handled privately. See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |
| Anything else | [hello@mayura.ai](mailto:hello@mayura.ai) or [mayura.ai/contact](https://mayura.ai/contact) |
